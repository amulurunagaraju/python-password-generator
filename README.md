Python Password Generator

About the Project:

This is a simple Python-based password generator that creates random passwords based on the user's preferred number of digits, symbols, and letters.

The program allows users to customize the composition of their passwords and generates a shuffled password using Python's built-in random module.

Features:

- Takes user input for the number of digits, symbols, and letters.
- Generates random digits, symbols, and lowercase letters.
- Combines and shuffles the selected characters to create a password.
- Checks for negative or invalid inputs.
- Provides basic password strength feedback based on password length.

Technologies Used:

- Python

Concepts Applied:

- Functions
- Loops
- Lists
- Random Module
- String Manipulation
- Conditional Statements
- Exception Handling

How to Run:

1. Make sure Python is installed on your system.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run the following command:

python password_generator.py

5. Enter the required number of digits, symbols, and letters.

Learning Outcome:

Through this project, I practised Python programming concepts such as functions, loops, lists, random selection, and string operations while developing a user-input-based password generator.
